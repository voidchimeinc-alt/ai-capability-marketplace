# Component Guide

## Principles

- One job per section/component.
- Cards only when they contain interaction or comparison units.
- Huge type, calm motion, sharp hierarchy.
- Brand tokens from CSS variables — never hard-code the product name in components.

## Core components

| Component | Purpose |
|-----------|---------|
| `ToolCard` | Atlas directory item |
| `ToolProfile` | Full entity page |
| `CapabilityScore` | Score bar / meter |
| `PersonalityCard` | Editorial personality |
| `ComparisonTable` | 2–5 system compare |
| `BenchmarkCard` | Arena challenge |
| `BuilderCard` / `BuilderProfile` | Network profiles |
| `ProofOfWorkCard` | Verified/self-reported projects |
| `ProjectCard` / `ProjectApplication` | Marketplace |
| `RecommendationPanel` | Stack recommendation output |
| `SearchCommand` | Signature search |
| `VerificationBadge` | Proof status |
| `EmptyState` | Calm empty UX |

## Motion

Use Motion for page hero entrance, score fills, and comparison reveal only.
